پروژه اندروید «باشگاه بازی‌های ذهنی» - نسخه ۲٫۰

شش بازی مستقل و کاملاً آفلاین:
۱) چالش ذهن: جمع، تفریق، ضرب و تقسیم تصادفی با گزینه‌های پاسخ، زمان محدود و سه سطح دشواری.
۲) ترتیب اعداد: انتخاب اعداد نامنظم از ۱ تا ۲۰، ۲۵، ۳۰، ۳۵ یا ۴۰ در زمان محدود.
۳) چشم عقاب: تمرین توجه و جست‌وجوی دیداری.
۴) تشخیص رنگ‌ها: پیدا کردن رنگ خواسته‌شده.
۵) تعقیب چند نقطه: دنبال کردن نقطه هدف در حرکت.
۶) شکل متفاوت: تشخیص شکل متفاوت از میان شکل‌های مشابه.

ویژگی‌ها:
- هر بازی صفحه مستقل دارد و از منوی اصلی قابل انتخاب است.
- رابط فارسی و راست‌چین؛ اعداد در بازی ترتیب اعداد انگلیسی هستند.
- طراحی سازگار با صفحه‌نمایش تلفن همراه.
- رکوردها روی همان دستگاه ذخیره می‌شوند.
- برای اجرای بازی‌ها نیازی به اینترنت نیست.

ساخت APK:
۱) وارد زبانه Actions مخزن GitHub شوید.
۲) گردش کار Build Android APK را انتخاب کنید.
۳) گزینه Run workflow را بزنید یا پس از ثبت تغییرات، اجرای خودکار را باز کنید.
۴) پس از پایان موفق ساخت، فایل MindNumberChallenge-debug-apk را از بخش Artifacts همان اجرا دریافت کنید.

توجه:
فایل APK ساخته‌شده با این گردش کار نسخه debug است. برای انتشار تجاری در فروشگاه‌ها، باید نسخه release با کلید امضای اختصاصی تهیه و آزمایش شود.
