پروژه اندروید بازی تقویت ذهن

ویژگی‌ها:
- آفلاین و بدون مجوز اینترنت
- مراحل 20، 25، 30، 35 و 40 عددی
- اعداد انگلیسی و ترتیب تصادفی
- زمان هر دور: 20 ثانیه
- ذخیره بهترین رکورد هر مرحله روی دستگاه

ساخت APK:
1. Android Studio را نصب کنید.
2. همین مخزن را Clone کنید یا از GitHub به صورت ZIP دریافت کنید.
3. پوشه پروژه را در Android Studio باز کنید و Gradle Sync را انجام دهید.
4. از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کنید.
5. فایل خروجی: app/build/outputs/apk/debug/app-debug.apk

نیازمندی: JDK 17 و Android Gradle Plugin 8.7.3.
