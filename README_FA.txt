# باشگاه بازی‌های ذهنی — نسخه ۲٫۳

یک برنامه اندرویدی فارسی با شش بازی مستقل. اجرای بازی‌ها و ذخیره رکوردها به‌صورت محلی انجام می‌شود.

## بازی‌ها
۱. چالش ذهن: جمع، تفریق، ضرب و تقسیم با گزینه‌های پاسخ و زمان محدود.
۲. ترتیب اعداد: انتخاب اعداد نامنظم از ۱ تا ۲۰، ۲۵، ۳۰، ۳۵ یا ۴۰.
۳. چشم عقاب: تمرین توجه و جست‌وجوی دیداری.
۴. تشخیص رنگ‌ها: پیدا کردن رنگ خواسته‌شده.
۵. تعقیب چند نقطه: دنبال‌کردن نقطه هدف.
۶. شکل متفاوت: پیدا کردن شکل ناهماهنگ.

## ساخت نسخه آزمایشی
در GitHub Actions گردش کار **Build Android APK** را اجرا کنید. خروجی debug فقط برای آزمایش است و نباید به‌عنوان نسخه نهایی فروشگاهی معرفی شود.

## انتشار امضاشده
برای انتشار برنامه جدید در Google Play، هدف برنامه باید Android 16 / API 36 یا بالاتر باشد. این پروژه روی API 36 تنظیم شده است. گردش کار **Signed Android release** با تگ نسخه مانند `v2.3`، APK و Android App Bundle امضاشده می‌سازد و در GitHub Releases منتشر می‌کند.

پیش از اجرای انتشار، یک مسئول بزرگسال باید کلید امضای اختصاصی بسازد و چهار مقدار زیر را در Settings → Secrets and variables → Actions مخزن ثبت کند:
- `ANDROID_KEYSTORE_BASE64`: محتوای فایل keystore به صورت Base64
- `ANDROID_STORE_PASSWORD`: رمز keystore
- `ANDROID_KEY_ALIAS`: نام alias
- `ANDROID_KEY_PASSWORD`: رمز کلید

**کلید keystore و رمزهای آن را در مخزن، کد، پیام یا گفت‌وگو قرار ندهید.** از کلید پشتیبان امن تهیه کنید؛ گم‌شدن کلید می‌تواند به‌روزرسانی نسخه‌های خارج از Play App Signing را دشوار یا ناممکن کند.

## وضعیت اشتراک
صفحه چهار دوره اشتراک نمایشی است؛ خرید عمداً غیرفعال است تا درگاه پرداخت و سرور امن تأیید تراکنش متصل شوند. هیچ پرداختی از برنامه دریافت نمی‌شود.

## پیش از انتشار در فروشگاه
- آزمایش نصب و بازی‌ها روی چند دستگاه واقعی و نسخه‌های مختلف Android
- تکمیل صفحه فروشگاه، تصاویر، رده‌بندی سنی و فرم Data safety
- انتشار سیاست حریم خصوصی در یک نشانی وب عمومی و فعال
- بازبینی شرایط حساب توسعه‌دهنده و قراردادهای فروشگاه توسط بزرگسال مسئول

سیاست فعلی حریم خصوصی داخل برنامه و در پوشه docs موجود است. برای انتشار عمومی، یک مسئول بزرگسال باید در مخزن به Settings → Pages برود و Source را روی GitHub Actions بگذارد؛ سپس از Actions گردش کار Publish privacy policy page را اجرا کند. پس از موفقیت، URL نمایش‌داده‌شده در خروجی Pages را بررسی و همان URL را در Play Console ثبت کنید. این نشانی تا پیش از فعال‌سازی Pages فعال نیست.
