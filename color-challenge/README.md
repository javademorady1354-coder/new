# چالش تشخیص رنگ‌ها – APK مستقل

این پروژه یک برنامه مستقل اندروید است و در اپلیکیشن اصلی ادغام نمی‌شود.

- پنج مرحله، هر مرحله ۳۰ سؤال (۱۵۰ سؤال)
- فقط سؤال اول هماهنگ؛ ۱۴۹ سؤال بعدی ناهمخوان
- زمان کل قابل انتخاب: ۲۰، ۳۰، ۶۰ و ۱۲۰ ثانیه
- امتیاز و رکورد محلی، توقف/ادامه و خروج واقعی از Activity
- اجرا کاملاً آفلاین با WebView و بدون مجوز اینترنت

## ساخت
از GitHub Actions گردش کار Build Color Word Challenge APK را اجرا کنید. فایل APK به‌عنوان artifact با نام color-word-challenge-standalone-apk بارگذاری می‌شود.
