بازگشت به برنامه

سیاست حفظ حریم خصوصی باشگاه بازی‌های ذهنی

آخرین به‌روزرسانی: ۳۰ آبان ۱۴۰۵

اطلاعات ذخیره‌شده

بازی‌ها برای ثبت امتیاز و رکورد، اطلاعات بازی را فقط در حافظه محلی همین دستگاه نگه می‌دارند. این رکوردها به حساب کاربری یا سرور ارسال نمی‌شوند. برنامه حساب کاربری ایجاد نمی‌کند و در نسخه فعلی تبلیغات، ابزار تحلیل رفتار یا ردیابی ندارد.

اتصال اینترنت

اجرای شش بازی به اینترنت نیاز ندارد. فقط اگر کاربر خودش صفحه «بررسی به‌روزرسانی» را باز کند و دکمه بررسی را بزند، برنامه برای دریافت اطلاعات انتشار نسخه جدید به API عمومی GitHub متصل می‌شود. GitHub ممکن است اطلاعات فنی معمول اتصال مانند نشانی IP را طبق سیاست حریم خصوصی خودش پردازش کند. برنامه این اطلاعات را برای ردیابی کاربر ذخیره نمی‌کند.

اشتراک و پرداخت

در نسخه فعلی، خرید اشتراک غیرفعال است و هیچ پرداختی انجام نمی‌شود. اگر در آینده درگاه پرداخت یا امکانات آنلاین اضافه شود، این سیاست پیش از فعال‌سازی آن‌ها به‌روزرسانی خواهد شد.

حذف اطلاعات و تماس

برای پاک‌کردن رکوردها از گزینه پاک‌کردن رکورد در بازی استفاده کنید یا داده‌های برنامه را از تنظیمات دستگاه پاک کنید. برای پرسش یا درخواست درباره حریم خصوصی، از بخش Issues مخزن پروژه استفاده کنید: تماس با پشتیبانی پروژه.

این سیاست فقط درباره نسخه فعلی برنامه است و باید با تغییر قابلیت‌ها بازبینی شود.
